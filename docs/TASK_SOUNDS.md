# Задание: звуки прибора

Для мода **Hiking GPS** к игре PEAK. Шесть коротких звуковых файлов.

Задание самодостаточное: всё, что нужно знать о приборе и об игре, есть ниже.

---

## Что за прибор

Рыжий прорезиненный ручной GPS-навигатор, примерно 9 × 12 см, с маленьким
экраном, тремя кнопками и короткой антенной. Игрок держит его **двумя руками**,
подняв к лицу, посреди подъёма на гору. Кнопки: приблизить, отдалить, наклонить
вид.

Игра кооперативная, до четырёх человек. Предмет находится в мире, а не в
интерфейсе, поэтому **звуки слышит не только владелец**, а все, кто рядом.

## В какой мир это должно вписаться

PEAK стилизованная, тёплая, слегка мультяшная. Прибор — не смартфон и не
научная фантастика: дешёвый пластиковый корпус, маленький монодинамик или
пьезо-пищалка. Характерный и чуть игрушечный, но без сай-фая.

Главное ограничение по вкусу, и оно важнее всех остальных:

> **Звук кнопки игрок услышит за подъём сотни раз.**

Нажатие на зум — это серия из пяти-шести нажатий подряд, и так каждые несколько
минут в течение часа. Всё, что имеет мелодию, узнаваемый мотив или заметный
хвост, к двухсотому разу станет пыткой и заставит человека выключить звук мода
целиком. Коротко, сухо, без послезвучия.

---

## Формат, и почему именно такой

**Моно, WAV, 16 бит PCM, 44 100 Гц.**

- **Моно — жёсткое требование, а не предпочтение.** Предмет находится в мире, и
  звук пространственный: движок сводит его в стерео сам, исходя из того, где
  предмет относительно ушей слушателя. Стереофайл спатиализировать невозможно —
  он прозвучит одинаково в обоих ушах откуда бы ни шёл, и напарник в двадцати
  метрах услышит щелчок так же громко и с той же стороны, как владелец.
- **WAV, а не OGG или MP3.** Файлы вкладываются внутрь DLL мода и разбираются
  там десятком строк. Сжатым форматам движку нужен временный файл на диске и
  асинхронная загрузка — лишняя точка отказа ради экономии, которой при таких
  длительностях всё равно не будет.
- **44 100 Гц, 16 бит.** 48 кГц и 24 бита не дадут ничего слышимого на щелчке
  длиной восемьдесят миллисекунд и только раздуют сборку.

## Требования к каждому файлу

- **Без тишины в начале.** Первая ненулевая выборка — в первых 2 мс. Иначе
  щелчок опаздывает за нажатием, и это отчётливо чувствуется, хотя человек не
  всегда понимает, что именно не так.
- **Затухание последних 5 мс в ноль.** Обрыв на ненулевой выборке даёт
  собственный щелчок поверх задуманного.
- **Нулевое постоянное смещение** (DC offset).
- **Сухо, без реверберации.** Пространство добавит игра: прибор звучит
  по-разному в лесу, в пещере и в снежном цирке, и запечённая в файл комната
  будет спорить с тем, что происходит вокруг.
- **Пик нормализован в −6 dBFS.** Запас оставлен намеренно.
- **Одинаковая воспринимаемая громкость по всему набору**, чтобы коду не
  пришлось выкручивать каждому файлу свой множитель. При этом щелчки должны
  быть субъективно *тише* тональных: они звучат многократно чаще.

## Список

| Файл | Длительность | Что это |
|---|---|---|
| `power_on.wav` | 300–400 мс | Прибор просыпается: мягкий щелчок контакта, затем короткий восходящий двухтональный сигнал — «поймал спутники». Чуть лоу-фай, как из дешёвого динамика. |
| `power_off.wav` | 200–300 мс | То же нисходящее, заканчивается щелчком. Должно узнаваемо быть парой к предыдущему. |
| `click_a.wav` | 60–90 мс | Упругий щелчок резиновой кнопки. Плотный, короткий, без звона. |
| `click_b.wav` | 60–90 мс | То же, едва иначе. |
| `click_c.wav` | 60–90 мс | То же, едва иначе. |
| `zoom_limit.wav` | 100–150 мс | Глухой низкий стук: лестница масштаба кончилась, дальше некуда. Заметно тише щелчка, по характеру явно «отрицательный», но не сигнал ошибки — прибор не сломался, просто дальше не бывает. |

**Про три щелчка.** Код берёт их вперемешку по кругу. Технически хватило бы
одного файла, но серия из шести нажатий одним и тем же сэмплом звучит как
пулемётная очередь — ухо мгновенно слышит машину. Различия должны быть **едва
заметны по отдельности и отчётливы в серии**: чуть иной призвук, чуть иная
атака, чуть иная длина хвоста. Это не три разных звука, это один звук трижды.

**Чего делать не надо:**

- периодического «пиканья» GPS-приёмника — в кооперативе это доведёт напарников
  до белого каления за пять минут;
- звука при появлении маркера на карте — их бывает десяток за минуту;
- музыкальных фраз и аккордов;
- звуков поднятия, броска и удара предмета — игра играет свои собственные.

## Что сдать

- шесть WAV по таблице, именами ровно как в ней;
- `preview.wav` — те же шесть подряд, в порядке таблицы, с паузами по 300 мс.
  Нужен, чтобы весь набор можно было прослушать одним нажатием и услышать, ровно
  ли он звучит как один прибор;
- короткий `README.md`: длительность, пиковый и среднеквадратичный уровень
  каждого файла и чем обрабатывали.

## Проверка перед сдачей

Прогоните и приложите вывод. Нужен только стандартный Python, без библиотек.

```python
import wave, struct, math, os

EXPECT = {
    "power_on.wav":   (0.300, 0.400),
    "power_off.wav":  (0.200, 0.300),
    "click_a.wav":    (0.060, 0.090),
    "click_b.wav":    (0.060, 0.090),
    "click_c.wav":    (0.060, 0.090),
    "zoom_limit.wav": (0.100, 0.150),
}

def db(x):
    return -math.inf if x <= 0 else 20 * math.log10(x)

print(f"{'файл':<16} {'сек':>6} {'пик dBFS':>9} {'RMS dBFS':>9} {'DC':>8}  замечания")
print("-" * 78)

problems = 0
for name, (lo, hi) in EXPECT.items():
    if not os.path.exists(name):
        print(f"{name:<16} ФАЙЛА НЕТ"); problems += 1; continue

    with wave.open(name, "rb") as w:
        ch, width, rate, frames = w.getnchannels(), w.getsampwidth(), w.getframerate(), w.getnframes()
        raw = w.readframes(frames)

    notes = []
    if ch != 1:     notes.append(f"НЕ МОНО ({ch} кан.)")
    if width != 2:  notes.append(f"НЕ 16 БИТ ({width * 8})")
    if rate != 44100: notes.append(f"НЕ 44100 ({rate})")

    if width != 2 or ch != 1:
        print(f"{name:<16} {'':>6} {'':>9} {'':>9} {'':>8}  " + ", ".join(notes)); problems += 1; continue

    s = struct.unpack("<%dh" % frames, raw)
    seconds = frames / rate
    peak = max(abs(v) for v in s) / 32768
    rms = math.sqrt(sum(v * v for v in s) / len(s)) / 32768
    dc = sum(s) / len(s) / 32768

    if not (lo <= seconds <= hi):
        notes.append(f"длительность вне {lo}-{hi} с")

    # тишина в начале: первая выборка выше 1% пика
    threshold = peak * 0.01 * 32768
    onset = next((i for i, v in enumerate(s) if abs(v) > threshold), 0)
    if onset / rate > 0.002:
        notes.append(f"тишина в начале {onset / rate * 1000:.0f} мс")

    # хвост: последние 5 мс должны сходить в ноль
    tail = s[-int(rate * 0.005):]
    if tail and max(abs(v) for v in tail) > peak * 0.05 * 32768:
        notes.append("хвост обрывается, не затухает")

    if abs(dc) > 0.001:
        notes.append("постоянное смещение")

    if not (-8 < db(peak) < -4):
        notes.append(f"пик не в −6 dBFS")

    if notes: problems += 1
    print(f"{name:<16} {seconds:>6.3f} {db(peak):>9.1f} {db(rms):>9.1f} {dc:>8.4f}  "
          + (", ".join(notes) if notes else "ок"))

print("-" * 78)
print("замечаний:", problems, " <-- должно быть 0")
```

Отдельно послушайте `preview.wav` целиком **дважды подряд**, а щелчки —
десять раз подряд. Набор, приятный с первого раза и невыносимый с десятого,
здесь не годится: именно так его и будут слышать.
